# THU 抑智小游戏（xinyarennengfei · NEW YA PEOPLE CAN FLY）

高校主题网页小游戏合集 · 纯前端 / 零依赖 / 离线可玩。包含 6 个玩法：Flappy 式飞行、合成大球、跑酷、五子棋、围棋与切水果，全部围绕清华/北大等高校校徽与"新雅人会飞"彩蛋展开。

> 🎮 在线试玩：https://ac10982dd4d05b3fd.app.workbuddy.link
> 制作人：sqx ｜ 主题彩蛋：新雅人会飞

## ✨ 特性
- **零依赖单页应用**：打开 `index.html` 即可玩，无需安装任何库；资源本地化，离线可用
- **6 个玩法**（主界面卡片即可切换）
  1. 🕊️ **清华人会飞** —— 操控校徽穿越管道吃★，10/20/30/40/50 分触发 白昼→傍晚→黑夜→二校门→校徽变身→标语+奶龙笑声 五段彩蛋；简单/困难双模式
  2. 🍡 **合成大清华** —— 自研圆体物理合成，北大→人大→…→清华 11 级，随投放次数逐步解锁高阶，通关计时榜
  3. 🏃 **清华跳跳龙** —— 紫人吉祥物跑酷（严肃脸奔跑/大笑跳跃+腿部动画），躲地面与空中悬浮北大徽，二段跳
  4. ⚫⚪ **清北五子棋** —— 15×15，真实校徽立体棋子，本地双人 / AI 初·中级 / WebRTC 联机（手动交换 SDP）
  5. ⚫⚪ **清北围棋** —— 19×19，提子/打劫/双停一手数子终局，每步 120s，AI / 联机
  6. 🍉 **马农出击** —— 水果忍者：C9 校徽当水果切，清华榴莲 +3、北大💣炸弹一切即终，5 命 + 前 50 实时榜
- **移动端友好**：手机/平板竖屏触摸可玩；主页针对窄屏/矮屏做了适配
- **昵称系统**：进入计分游戏前创建本机唯一昵称；各玩法带**本机前 50 实时排行榜**
- 背景乐为清华《新雅序曲》（已去除首尾鼓掌，214s 循环）；50 分彩蛋播放真实奶龙笑声

## 🚀 本地运行
```bash
# 方式一：本地静态服务器（推荐）
cd <本仓库根目录>
python -m http.server 8000
# 浏览器打开 http://localhost:8000

# 方式二：直接双击 index.html（基本可用；个别浏览器对 file:// 的存储/音频有限制）
```

## 🔧 技术要点（给贡献者的索引）
- 存储键统一 `qh_` 前缀：昵称 `qh_me`、占用名单 `qh_used`、排行榜 `qh_lb_g1/g2/g3/qh_lb_fruit` 等
- 实时徽章绘制统一入口 `badge(ctx, school, x, y, r, opt)`（真实图片圆形裁切 + 校徽色光晕 + 立体高光）
- 游戏 4/5/6 为 iframe 单文件模式；返回主页走 `goMenu()`
- 切水果使用真实抛体物理：恒定重力积分 + `v=√(2gh)` 反推初速；漏果需"过顶点回落后再掉出底部"才扣命
- 校徽图片为真实院校徽章，程序内已做圆形美化；更多结构说明见代码内注释
